# DocuMind — Source Map

> Complete inventory of every source file and its purpose. Use this as a reference when navigating the codebase.

---

## Project Root (`AI_project_clean/`)

| File | Lines | Purpose |
|------|-------|---------|
| `retrieval.py` | 121 | **Core retrieval engine.** Embeds query → FAISS ANN search → geometry-based deterministic reranking → returns `EvidenceBlock` list. |
| `embedding_service.py` | 69 | **Embedding model singleton.** Lazy-loads BGE-small-en-v1.5 (384-dim). Provides `embed_texts()` for documents and `embed_query()` with BGE instruction prefix for queries. |
| `semantic_chunker.py` | 630 | **Semantic chunking pipeline.** Multi-source text acquisition → Unicode cleaning → spaCy sentence detection → block detection + tagging (caption, equation, table, text) → overlapping windows → PostgreSQL persistence. |
| `block_extractor.py` | 647 | **Geometry-aware block extraction.** PyMuPDF page → raw blocks with bounding box → deterministic classification (header/footer/table/paragraph/etc.) → `DocumentBlock` dataclass → PostgreSQL `document_blocks` table. |
| `db.py` | 69 | **Root DB helper.** Loads `.env`, builds `DATABASE_URL` from env vars, returns psycopg2 connections. (Note: `app/db.py` is the canonical version used by the app.) |
| `db_test.py` | ~6 | Minimal DB connection test script. |
| `analyze_profile.py` | ~60 | Analyzes `.prof` files generated by Werkzeug ProfilerMiddleware. Outputs top-N slowest functions. |
| `run_profiled.py` | ~15 | Starts the Flask app with `FLASK_PROFILE=1` enabled. |
| `.env.example` | 35 | Template for environment variables (secrets, DB, Redis, OAuth, SMTP). |
| `run-dev.bat` | ~40 | Windows batch script for starting dev servers. |
| `run-dev.ps1` | ~80 | PowerShell script for starting dev servers. |
| `start-servers.bat` | ~20 | Simplified Windows server starter. |
| `start-servers.ps1` | ~40 | Simplified PowerShell server starter. |
| `start-servers-profiled.bat` | ~25 | Starts servers with profiling enabled. |

## Flask Backend (`app/`)

| File | Lines | Purpose |
|------|-------|---------|
| `__init__.py` | 57 | **App factory.** Creates Flask instance, configures secret key, CORS, cookie hardening, profiling middleware, registers Blueprint. |
| `routes.py` | 532 | **All HTTP routes.** Auth endpoints (register/login/OAuth/password-reset), upload, ask, chat, document API, health check. Delegates to services. |
| `auth_service.py` | 537 | **Authentication logic.** User registration (bcrypt), login verification, Google OAuth (code exchange → userinfo → upsert), OTP password reset with SMTP delivery. |
| `redis_client.py` | 482 | **Document text storage.** Redis put/get with gzip compression, chunked storage for large docs, in-memory fallback, legacy chunk builder that delegates to semantic_chunker. |
| `storage.py` | 101 | **File format helpers.** PDF extraction (PyMuPDF), DOCX extraction, OCR (Tesseract), text file reading, naive keyword search, human-readable size formatter. |
| `upload_flow.py` | 128 | **Upload pipeline orchestrator.** Generates doc_id → Redis store → PostgreSQL metadata → block extraction → background embedding thread. |
| `faiss_index.py` | 137 | **FAISS vector index.** HNSW Flat (384-dim, 32 connections). Thread-safe add/search. Integer ID → block_id mapping via pickle. Persists to disk. |
| `ingest_db.py` | 271 | **Database ingestion layer.** Document metadata inserts, chunk metadata bulk inserts, embeddings map inserts. Uses `app.db.get_conn()`. |
| `db.py` | 135 | **PostgreSQL connector.** Loads `.env`, builds `DATABASE_URL`, returns psycopg2 connections. (⚠️ File content is duplicated — lines 68-135 repeat lines 1-67.) |
| `db_test.py` | ~10 | Quick PostgreSQL connection test. |
| `wsgi.py` | 3 | **WSGI entry point.** `from app import create_app; app = create_app()`. Used by Gunicorn. |
| `gunicorn_conf.py` | 5 | Gunicorn configuration (workers, bind address). |
| `Dockerfile` | ~10 | Docker image definition for Flask backend. |
| `docker-compose.yml` | ~20 | Docker Compose for Flask + Redis + PostgreSQL. |
| `requirements.txt` | 31 | Python dependencies. (⚠️ Contains non-pip env var lines.) |
| `Readme.md` | ~30 | App README. |
| `documind_landing.tsx` | ~350 | **Misplaced file** — TSX component in Flask backend directory. Should be in `frontend/components/`. |
